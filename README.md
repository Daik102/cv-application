<h1>Project: CV Application</h1>

A CV app with several features<br>
This project is based on <a href="https://www.theodinproject.com/" target="_blank" rel="noreferrer">The Odin Project</a>.

<h3>Features</h3>

- Live CV rendering using useState

- Smooth dialog transitions using useRef and @starting-style

- Constraint validation API

- Restoring data using useEffect and localStorage

- Responsive Design implemented

<h3>Tech Stack</h3>

- Frontend: React, CSS, JavaScript

- Build Tool: Vite
